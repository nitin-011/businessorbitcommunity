# BusinessOrbitCommunity

BusinessOrbitCommunity is a small web project built with TypeScript, JavaScript, and CSS that aims to provide a simple hub for business professionals to connect, share resources, and discuss ideas.

## Features

- Community discussions and resource sharing
- Event listings and announcements
- Lightweight, responsive UI

## Tech stack

- TypeScript
- JavaScript
- CSS

## Getting started

Prerequisites:
- Node.js (14+)
- npm or yarn

Install dependencies:

```bash
npm install
# or
# yarn install
```

Run the development server:

```bash
npm run dev
# or
# npm start
```

Build for production:

```bash
npm run build
```
